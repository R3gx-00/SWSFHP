This is a simple webscrapper project.
The goal of the webscrapper is to collect data of housing prices in certain citties.
This program is for private use only.

Use this in the command line to open a web browser for scrapping
google-chrome --remote-debugging-port=9222 --user-data-dir=/tmp/chrome-debug

or try this on pc
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\chrome-debug"
"C:\Program Files (x86)\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\chrome-debug"
